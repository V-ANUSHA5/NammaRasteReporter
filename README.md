# NammaRasteReporter

NammaRasteReporter is an Android application developed to help users report road-related issues such as potholes, garbage, drainage problems, and damaged roads. The app allows citizens to quickly capture and upload complaints with location details, making it easier for authorities to identify and resolve civic problems efficiently.

## Features

* User-friendly Android interface
* Report road issues with images
* GPS/location-based complaint tracking
* Categorization of road and civic problems
* Real-time complaint submission
* Simple and responsive UI
* Firebase/Backend integration for data storage
* Complaint management and tracking

## Technologies Used

* Kotlin
* Android Studio
* XML
* Firebase
* Git & GitHub

## Project Objective

The main objective of NammaRasteReporter is to improve road maintenance and civic issue reporting by providing a digital platform where users can directly report issues from their mobile devices.
